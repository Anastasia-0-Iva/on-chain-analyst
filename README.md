# On-chain-analyst — Анализатор спящих Ethereum-кошельков

## О проекте
On-chain-analyst — исследовательский инструмент для обнаружения и анализа «спящих» (dormant) кошельков в сети Ethereum. Проект реализует полный пайплайн работы с блокчейн-данными: от сбора адресов через публичное API до анализа на «призрачность» по балансу и времени последней активности.

**Ключевая особенность**: Весь анализ построен на реальных данных, полученных через официальное Etherscan API, без использования синтетических или сгенерированных датасетов.

## Возможности
- **Автоматический сбор адресов**: Извлечение уникальных адресов из транзакций популярных контрактов (WETH, USDT, USDC)
- **Анализ «призрачности»**: Проверка двух ключевых критериев:
  - **Баланс > 0.01 ETH** (фильтрация «пыли»)
  - **Бездействие > 3 лет** (расчёт времени с последней транзакции)
- **Профессиональная обработка данных**: Полный цикл ETL (Extract, Transform, Load) в рамках одного скрипта
- **Детальная статистика**: Анализ распределения адресов по категориям (активные, малобалансные, без транзакций)

## Технологический стек
- **Python 3.8+** — основной язык разработки
- **Etherscan API** — источник данных о балансах и транзакциях
- **Requests** — работа с HTTP-запросами
- **Модульная архитектура** — разделение логики сбора и анализа данных

## Методология работы
Проект реализует чёткий пайплайн анализа:

1. **Этап сбора (Data Collector)**:
   - Получение последних транзакций контрактов WETH, USDT, USDC через `txlist`
   - Извлечение уникальных адресов участников (отправителей и получателей)
   - Сохранение датасета в формате JSON для последующего анализа

2. **Этап анализа (Ghost Analyzer)**:
   - Проверка баланса каждого адреса через `balance`
   - Определение даты последней транзакции через `txlist` с параметром `sort='desc'`
   - Применение критериев «призрачности» и классификация адресов
   - Генерация детальной статистики выполнения

## Производительность и ограничения
- **Ограничения API**: Работа в рамках бесплатного тарифа Etherscan (5 запросов/сек, 100к запросов/день)
- **Оптимизация запросов**: Интеллектуальные паузы (`time.sleep(0.25)`) для соблюдения лимитов
- **Масштабируемость**: Архитектура позволяет легко увеличивать объём анализируемых данных
- **Обработка ошибок**: Корректная реакция на сбои API и сетевые проблемы

## Установка и запуск

### Предварительные требования
1. **API-ключ Etherscan**: Зарегистрируйтесь на [Etherscan](https://etherscan.io/) и получите бесплатный API-ключ
2. **Python 3.8+**: Убедитесь, что Python установлен в системе

### Клонирование и настройка
```bash
# 1. Клонируйте репозиторий
git clone https://github.com/Anastasia-0-Iva/on-chain-analyst.git
cd on-chain-analyst

# 2. Создайте и активируйте виртуальное окружение
python -m venv venv
# Для Windows:
venv\Scripts\activate
# Для Linux/Mac:
source venv/bin/activate

# 3. Установите зависимости
poetry install

# 4. Настройте API-ключ
# Создайте файл utils/API.py и добавьте:
# API_KEY = 'ваш_ключ_etherscan'
